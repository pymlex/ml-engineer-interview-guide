# 2. Классическое обучение с учителем


Данные есть набор пар $(x_i,y_i)$ для $i=1,\ldots,n$. Вектор $x_i\in\mathcal{X}$ — признаки объекта. Величина $y_i\in\mathcal{Y}$ — метка. Предполагают, что пары независимы и порождены одним неизвестным распределением $P$ на $\mathcal{X}\times\mathcal{Y}$. Цель — по выборке построить правило предсказания, которое хорошо работает на новых парах из того же $P$.


## Риск и эмпирический риск


Функция потерь $\ell(\hat y,y)$ задаёт цену ошибки, когда модель выдала $\hat y$, а истина равна $y$. Истинный риск модели $f$ есть среднее потери по распределению данных:


```math
R(f)=\mathbb{E}_{(x,y)\sim P}\bigl[\ell(f(x),y)\bigr].
```


Распределение $P$ неизвестно, поэтому $R(f)$ напрямую не минимизируют. Вместо него берут среднее по обучающей выборке — эмпирический риск:


```math
\hat R_n(f)=\frac1n\sum_{i=1}^{n}\ell(f(x_i),y_i).
```


Обучение с учителем в самой общей записи есть выбор $f$ из класса гипотез $\mathcal{F}$ по принципу минимизации эмпирического риска, возможно со штрафом на сложность.


## Смещение и дисперсия


Пусть $y=f^\star(x)+\varepsilon$, где $f^\star$ — неизвестная регрессионная функция, а $\varepsilon$ — шум с нулевым средним и дисперсией $\sigma^2$. По случайной обучающей выборке $D$ строят оценку $\hat{f}$. Среднее этой оценки по всевозможным выборкам того же размера обозначают $\bar{f}(x)$.

Для квадратичной потери ожидание ошибки в точке, взятое по выборке $D$ и по шуму $\varepsilon$, раскладывается так:


```math
\mathbb{E}\bigl[(y-\hat{f}(x))^2\bigr]
=
\sigma^2
+\bigl(\bar{f}(x)-f^{\star}(x)\bigr)^2
+\mathbb{E}\bigl[(\hat{f}(x)-\bar{f}(x))^2\bigr].
```


Первое слагаемое — неустранимый шум меток. Второе — квадрат смещения: насколько средний по выборкам предиктор далёк от $f^{\star}$. Третье — дисперсия: насколько предиктор прыгает при смене обучающей выборки.

Класс гипотез малой ёмкости обычно даёт большое смещение и малую дисперсию. Класс большой ёмкости снижает смещение на обучении и поднимает дисперсию. Переобучение — режим, в котором ошибка на обучающей выборке мала, а на новых данных велика. Недообучение — режим, в котором ошибка велика и на обучении, и на новых данных.


## Проклятие размерности и стратифицированный K-fold


Если признаки лежат в $\mathbb{R}^d$ при большом $d$, объём шара радиуса $r$ растёт как $r^d$. При фиксированном $n$ типичные расстояния между точками выравниваются, локальные методы теряют контраст соседства, а оценка ковариации требует объёма данных, растущего с $d$. Отсюда потребность в регуляризации, отборе признаков и снижении размерности.

Стратифицированный K-fold делит выборку на $K$ блоков так, чтобы доля каждого класса в блоке совпадала с долей в полной выборке. Модель $K$ раз обучают на $K-1$ блоках и оценивают на оставшемся. Итоговая оценка — среднее по блокам. Стратификация удерживает редкие классы во всех блоках.


## Линейная регрессия и RSS


Модель: $\hat y_i=w^\top x_i$. Свободный член включают в $x_i$ как координату, тождественно равную $1$, либо пишут отдельно $w^\top x_i+b$. Дальше для краткости считаем, что он уже внутри $x_i$.

Матрица признаков $X\in\mathbb{R}^{n\times d}$ имеет строки $x_i^\top$. Вектор ответов $\mathbf{y}=(y_1,\ldots,y_n)^\top$. Вектор предсказаний равен $Xw$.

Сумма квадратов остатков


```math
\mathrm{RSS}(w)=\sum_{i=1}^{n}(y_i-w^\top x_i)^2=\|Xw-\mathbf{y}\|_2^2.
```


В главе о математике показано: если $y_i=w^\top x_i+\varepsilon_i$ и $\varepsilon_i\sim\mathcal{N}(0,\sigma^2)$ независимы, то максимизация правдоподобия по $w$ эквивалентна минимизации RSS. При полном столбцовом ранге $X$ решение OLS единственно:


```math
\hat w=(X^\top X)^{-1}X^\top\mathbf{y}.
```


Геометрически $X\hat w$ есть ортогональная проекция $\mathbf{y}$ на столбцовое пространство $X$.


### Метрики регрессии


Среднеквадратичная ошибка и средняя абсолютная ошибка:


```math
\mathrm{MSE}=\frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2,
\qquad
\mathrm{MAE}=\frac1n\sum_{i=1}^{n}|y_i-\hat y_i|.
```


MSE сильнее штрафует крупные остатки. MAE устойчивее к выбросам.

Потеря Хьюбера с порогом $\delta>0$ для остатка $r=y-\hat y$ равна $\frac12 r^2$ при $|r|\le\delta$ и $\delta(|r|-\frac12\delta)$ при $|r|>\delta$. Вблизи нуля она ведёт себя как квадрат, на хвостах — как абсолютная величина.

MAPE усредняет $|y_i-\hat y_i|/|y_i|$ и ломается, когда знаменатель близок к нулю. SMAPE нормирует на полусумму $|y_i|$ и $|\hat y_i|$ и смягчает асимметрию MAPE.


## Логистическая регрессия: от Бернулли к сигмоиде и LogLoss


Постановка. Метка $y\in\{0,1\}$. Для объекта с признаками $x$ модель должна выдать вероятность


```math
p(y=1\mid x)=p(x)\in(0,1),
\qquad
p(y=0\mid x)=1-p(x).
```


Одно наблюдение имеет бернуллиевскую вероятность


```math
P(Y=y\mid x)=p(x)^{y}\bigl(1-p(x)\bigr)^{1-y}.
```


Для независимой выборки $(x_i,y_i)_{i=1}^{n}$ правдоподобие параметров, которые входят в $p(x_i)$, равно


```math
L=\prod_{i=1}^{n}p(x_i)^{y_i}\bigl(1-p(x_i)\bigr)^{1-y_i}.
```


Логарифмическое правдоподобие


```math
\ell=\sum_{i=1}^{n}\Bigl(
y_i\log p(x_i)+(1-y_i)\log\bigl(1-p(x_i)\bigr)
\Bigr).
```


Максимизация $\ell$ эквивалентна минимизации среднего отрицательного логарифма правдоподобия:


```math
\mathrm{BCE}
=-\frac1n\sum_{i=1}^{n}\Bigl(
y_i\log p(x_i)+(1-y_i)\log\bigl(1-p(x_i)\bigr)
\Bigr).
```


Эту величину называют бинарной кросс-энтропией и LogLoss. Пока никакой сигмоиды нет: LogLoss определён для любой модели, которая выдаёт число из $(0,1)$.


### Откуда берётся сигмоида


Линейная функция $z=w^\top x+b$ принимает любые вещественные значения и не лежит в $(0,1)$. Значит, нельзя положить $p(x)=w^\top x+b$.

В логистической регрессии линейно моделируют не вероятность, а логарифм шансов:


```math
\log\frac{p(x)}{1-p(x)}=w^\top x+b.
```


Левая часть называется логитом. Обозначим $z=w^\top x+b$. Тогда


```math
\frac{p}{1-p}=e^{z}
\implies
p=\frac{e^{z}}{1+e^{z}}
=\frac{1}{1+e^{-z}}.
```


Функция


```math
\sigma(z)=\frac{1}{1+e^{-z}}
```


есть логистическая сигмоида. Она отображает $\mathbb{R}$ в $(0,1)$, строго возрастает, и обратна к логиту. Сигмоида появляется как обратное преобразование к линейной модели логита, а не как отдельная эвристика рядом с LogLoss.

Подстановка $p(x_i)=\sigma(w^\top x_i+b)$ в BCE даёт функцию потерь логистической регрессии.


### Градиент


Производная сигмоиды: $\sigma'(z)=\sigma(z)\bigl(1-\sigma(z)\bigr)$. Дифференцирование BCE по $w$ после сокращений даёт


```math
\nabla_w\mathrm{BCE}
=\frac1n\sum_{i=1}^{n}\bigl(\sigma(w^\top x_i+b)-y_i\bigr)x_i.
```


Разность предсказанной вероятности и метки умножается на признаковый вектор. Функционал выпукл по $w$, поэтому локальный минимум глобален.

Для $K$ классов берут категориальное распределение. Логиты $z\in\mathbb{R}^K$ переводят в вероятности через Softmax:


```math
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}.
```


Отрицательный логарифм правдоподобия даёт категориальную кросс-энтропию.


## Регуляризация L2, L1 и Elastic Net


В главе о математике для гауссовской линейной модели выведено: если априорное распределение $w\sim\mathcal{N}(0,\tau^2 I)$, то MAP есть


```math
\hat w
=\arg\min_w\Bigl(\mathrm{RSS}(w)+\lambda\|w\|_2^2\Bigr),
\qquad
\lambda=\frac{\sigma^2}{\tau^2}.
```


Если априорное распределение лапласовское, MAP есть


```math
\hat w
=\arg\min_w\Bigl(\mathrm{RSS}(w)+\lambda\|w\|_1\Bigr).
```


Те же штрафы добавляют к BCE:


```math
\min_w\ \mathrm{BCE}(w)+\lambda\|w\|_2^2
\qquad\text{или}\qquad
\min_w\ \mathrm{BCE}(w)+\lambda\|w\|_1.
```


Для бернуллиевского правдоподобия и гауссовского априорного распределения на $w$ вторая задача снова есть MAP. На уровне оптимизации это минимизация эмпирического риска плюс штраф.

Штраф $\|w\|_2^2$ сжимает координаты к нулю непрерывно и редко обнуляет их точно. Штраф $\|w\|_1$ из-за угловатой геометрии единичного шара нормы $\|\cdot\|_1$ часто ставит часть координат ровно в ноль.

Elastic Net смешивает оба штрафа:


```math
\min_w\ \mathrm{RSS}(w)
+\lambda\bigl(\alpha\|w\|_1+(1-\alpha)\|w\|_2^2\bigr).
```


Член с $\|w\|_2^2$ стабилизирует оценку при коррелированных признаках. Член с $\|w\|_1$ сохраняет разреженность. Параметры $\lambda$ и $\alpha$ выбирают по валидации.


## Метрики классификации


По порогу на score строят матрицу ошибок с числами TP, FP, FN, TN.


```math
\mathrm{Recall}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}},
\qquad
\mathrm{Precision}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}}.
```


F1 — гармоническое среднее Precision и Recall:


```math
F_1=\frac{2\cdot\mathrm{Precision}\cdot\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}.
```


Macro-F1 усредняет F1 по классам с равными весами. Micro-F1 сначала суммирует TP, FP, FN по всем классам, затем считает одну F1. Weighted-F1 взвешивает классы по числу объектов.

ROC-кривая строится в осях False Positive Rate и True Positive Rate при варьировании порога. ROC-AUC равна вероятности того, что случайный объект положительного класса получит score выше, чем случайный объект отрицательного класса.

PR-кривая строится в осях Recall и Precision. PR-AUC информативнее ROC-AUC при сильном дисбалансе, когда отрицательный класс доминирует и раздувает область True Negative.

Каппа Коэна сравнивает наблюдаемую долю согласия $p_o$ с долей согласия $p_e$, ожидаемой при независимости маргиналов:


```math
\kappa=\frac{p_o-p_e}{1-p_e}.
```



## SVM


Ищут разделяющую гиперплоскость $w^\top x+b=0$. Метки удобно кодировать как $y_i\in\{-1,+1\}$. Геометрический зазор между опорными плоскостями $w^\top x+b=\pm 1$ равен $2/\|w\|$.

Задача жёсткого зазора требует безошибочного разделения:


```math
\min_{w,b}\ \frac12\|w\|_2^2
\quad\text{при ограничениях}\quad
y_i(w^\top x_i+b)\ge 1
\quad\text{для всех }i.
```


Если выборка линейно неразделима, вводят переменные $\xi_i\ge 0$ и штраф за их сумму. Задача мягкого зазора:


```math
\min_{w,b,\xi}\ \frac12\|w\|_2^2+C\sum_{i=1}^{n}\xi_i
\quad\text{при}\quad
y_i(w^\top x_i+b)\ge 1-\xi_i,\quad\xi_i\ge 0.
```


Параметр $C>0$ задаёт цену нарушения. Большое $C$ приближает жёсткий зазор. Эквивалентная запись через hinge-потерю:


```math
\min_{w,b}\ \frac12\|w\|_2^2
+C\sum_{i=1}^{n}\max\bigl(0,1-y_i(w^\top x_i+b)\bigr).
```


Двойственная задача зависит от данных через скалярные произведения $\langle x_i,x_j\rangle$. Ядерный трюк заменяет их на $K(x_i,x_j)=\langle\phi(x_i),\phi(x_j)\rangle$ без явного построения $\phi$.

Линейное ядро: $K(x,x')=x^\top x'$.  
Полиномиальное ядро: $K(x,x')=(x^\top x'+c)^d$.  
RBF-ядро:


```math
K(x,x')=\exp\bigl(-\gamma\|x-x'\|^2\bigr).
```


Параметр $\gamma$ задаёт ширину локальности. Перед ядерным SVM признаки обычно масштабируют.


## Случайный лес и OOB


Решающее дерево рекурсивно делит пространство признаков. Глубокое дерево может иметь малое смещение и большую дисперсию.

Случайный лес строит $B$ деревьев. Для каждого дерева:
1. берут бутстрэп-выборку из обучающих объектов;
2. при каждом разбиении рассматривают случайное подмножество из $m$ признаков;
3. растят дерево до заданного критерия остановки.

Итоговый ответ — голосование для классификации или усреднение для регрессии. Бэггинг и случайность признаков снижают корреляцию деревьев и тем самым дисперсию ансамбля.

Объекты, не попавшие в бутстрэп дерева $b$, образуют out-of-bag выборку этого дерева. Для объекта $i$ собирают предсказания тех деревьев, где $i$ был OOB, и получают оценку ошибки без отдельной валидационной выборки.


## Градиентный бустинг


Ищут сумму баз


```math
F_M(x)=\sum_{m=1}^{M}\nu\,h_m(x),
```


где $h_m$ — дерево, $\nu\in(0,1]$ — длина шага. На шаге $m$ текущая модель равна $F_{m-1}$. Для потери $\ell(y,F(x))$ считают псевдоостатки


```math
r_{im}=-\frac{\partial\ell(y_i,F(x_i))}{\partial F(x_i)}\Big|_{F=F_{m-1}}.
```


Дерево $h_m$ обучают приближать $\{r_{im}\}$. Затем обновляют $F_m=F_{m-1}+\nu h_m$. Так бустинг жадно снижает эмпирический риск.


### XGBoost


XGBoost использует разложение Тейлора второго порядка потери по добавке дерева и добавляет регуляризацию на число листьев и на нормы значений в листьях. Для листа $j$ с множеством объектов $I_j$ оптимальный вес листа


```math
w_j^\star=-\frac{\sum_{i\in I_j}g_i}{\sum_{i\in I_j}h_i+\lambda},
```


где $g_i$ — первая производная потери по предсказанию на объекте $i$, а $h_i$ — вторая производная. Параметр $\lambda$ штрафует большие веса листьев.


### LightGBM и CatBoost


LightGBM растят дерево листо-мудро, дискретизирует признаки гистограммами, усиливает вклад объектов с большими градиентами и объединяет взаимоисключающие разреженные признаки. Это снижает время построения дерева на больших таблицах.

CatBoost кодирует категориальные признаки упорядоченными статистиками целевой переменной, чтобы уменьшить утечку таргета, и использует симметричные деревья. Упорядоченный бустинг снижает сдвиг, связанный с использованием метки объекта при кодировании его же категорий.

Лес снижает дисперсию параллельным усреднением. Бустинг последовательно снижает смещение и чувствителен к числу деревьев $M$ и к шагу $\nu$. Early stopping фиксирует $M$ по валидационной метрике.
