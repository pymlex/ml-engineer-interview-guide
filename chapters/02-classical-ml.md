# 2. Классическое обучение с учителем


Данные есть набор пар $(x_i,y_i)$ для $i=1,\ldots,n$. Вектор $x_i\in\mathcal{X}$ — признаки объекта. Величина $y_i\in\mathcal{Y}$ — метка. Предполагают, что пары независимы и порождены одним неизвестным распределением $P$ на $\mathcal{X}\times\mathcal{Y}$. Цель — по выборке построить правило предсказания, которое хорошо работает на новых парах из того же $P$.


## Риск и эмпирический риск


Функция потерь $\ell(\hat{y},y)$ задаёт цену ошибки, когда модель выдала $\hat{y}$, а истина равна $y$. Качество модели $f$ на всём распределении данных измеряют истинным риском — средним потери по паре $(x,y)\sim P$:


```math
R(f)=\mathbb{E}_{(x,y)\sim P}\bigl[\ell(f(x),y)\bigr]
=\int \ell(f(x),y)\,dP(x,y).
```


Распределение $P$ неизвестно, интеграл посчитать нельзя. Есть только конечная выборка из $P$. Заменяют интеграл средним по выборке. Это эмпирический риск:


```math
\hat{R}_n(f)=\frac1n\sum_{i=1}^{n}\ell(f(x_i),y_i).
```


При независимых одинаково распределённых наблюдениях $\hat{R}_n(f)$ есть несмещённая оценка $R(f)$ для фиксированной $f$: 


```math
\mathbb{E}_{D}\bigl[\hat{R}_n(f)\bigr]=R(f).
```


Обучение с учителем в самой общей записи есть выбор $f$ из класса гипотез $\mathcal{F}$ по принципу минимизации эмпирического риска:


```math
\hat{f}\in\arg\min_{f\in\mathcal{F}}\hat{R}_n(f).
```


Часто к $\hat{R}_n$ добавляют штраф на сложность. Тогда минимизируют регуляризованный эмпирический риск.


## Смещение и дисперсия


Зафиксируем точку $x$ в пространстве признаков. Метка в этой точке порождается так:


```math
y=f^{\star}(x)+\varepsilon.
```


Здесь $f^{\star}(x)$ — неизвестное условное среднее ответа при данном $x$, то есть $f^{\star}(x)=\mathbb{E}[y\mid x]$. Шум $\varepsilon$ независим от обучающей выборки и удовлетворяет


```math
\mathbb{E}[\varepsilon]=0,\qquad \mathrm{Var}(\varepsilon)=\sigma^2.
```


Обучающая выборка $D=\{(x_1,y_1),\ldots,(x_n,y_n)\}$ случайна. Алгоритм по $D$ строит функцию $\hat{f}_D$. В фиксированной точке $x$ значение $\hat{f}_D(x)$ случайно из-за случайности $D$. Среднее по всем выборкам размера $n$ обозначают


```math
\bar{f}(x)=\mathbb{E}_{D}\bigl[\hat{f}_D(x)\bigr].
```


Интересует квадратичная ошибка предсказания в точке $x$. Усреднять нужно и по шуму новой метки, и по выбору обучающей выборки. Новую метку при том же $x$ считают независимой от $D$. Исходят из


```math
\mathbb{E}_{D,\varepsilon}\bigl[(y-\hat{f}_D(x))^2\bigr].
```


Подставляют $y=f^{\star}(x)+\varepsilon$ и добавляют, вычитают $\bar{f}(x)$:


```math
y-\hat{f}_D(x)
=\varepsilon+\bigl(f^{\star}(x)-\bar{f}(x)\bigr)+\bigl(\bar{f}(x)-\hat{f}_D(x)\bigr).
```


Обозначают


```math
A=\varepsilon,
\qquad
B=f^{\star}(x)-\bar{f}(x),
\qquad
C=\bar{f}(x)-\hat{f}_D(x).
```


Тогда $y-\hat{f}_D(x)=A+B+C$ и


```math
(y-\hat{f}_D(x))^2
=A^2+B^2+C^2+2AB+2AC+2BC.
```


Берут $\mathbb{E}_{D,\varepsilon}$ от обеих частей.

Член $B$ детерминирован при фиксированном $x$, поэтому


```math
\mathbb{E}_{D,\varepsilon}[B^2]=B^2=\bigl(f^{\star}(x)-\bar{f}(x)\bigr)^2.
```


Для шума:


```math
\mathbb{E}_{D,\varepsilon}[A^2]=\mathbb{E}_{\varepsilon}[\varepsilon^2]=\sigma^2,
```


поскольку $\mathbb{E}[\varepsilon]=0$.

Для отклонения оценки от своего среднего:


```math
\mathbb{E}_{D,\varepsilon}[C^2]
=\mathbb{E}_{D}\bigl[\bigl(\hat{f}_D(x)-\bar{f}(x)\bigr)^2\bigr].
```


Кресты обнуляются. Из $\mathbb{E}[\varepsilon]=0$ и независимости $\varepsilon$ от $D$:


```math
\mathbb{E}_{D,\varepsilon}[AB]
=\bigl(f^{\star}(x)-\bar{f}(x)\bigr)\cdot\mathbb{E}[\varepsilon]=0,
```


```math
\mathbb{E}_{D,\varepsilon}[AC]
=\mathbb{E}_{D}\bigl[\bar{f}(x)-\hat{f}_D(x)\bigr]\cdot\mathbb{E}[\varepsilon]=0.
```


Из определения $\bar{f}$:


```math
\mathbb{E}_{D,\varepsilon}[BC]
=\bigl(f^{\star}(x)-\bar{f}(x)\bigr)\cdot\mathbb{E}_{D}\bigl[\bar{f}(x)-\hat{f}_D(x)\bigr]=0.
```


Итого:


```math
\mathbb{E}_{D,\varepsilon}\bigl[(y-\hat{f}_D(x))^2\bigr]
=
\sigma^2
+\bigl(\bar{f}(x)-f^{\star}(x)\bigr)^2
+\mathbb{E}_{D}\bigl[(\hat{f}_D(x)-\bar{f}(x))^2\bigr].
```


Первое слагаемое — дисперсия шума. Второе — квадрат смещения. Третье — дисперсия алгоритма по выборкам.

Класс гипотез малой ёмкости обычно даёт большое смещение и малую дисперсию. Класс большой ёмкости снижает смещение и поднимает дисперсию. Переобучение — малая ошибка на обучении при большой ошибке на новых данных. Недообучение — большая ошибка и там, и там.


## Проклятие размерности и стратифицированный K-fold


Объём евклидова шара радиуса $r$ в $\mathbb{R}^d$ пропорционален $r^d$. Чтобы покрыть единичный куб шарами фиксированного радиуса, число шаров растёт экспоненциально с $d$. При фиксированном $n$ типичные попарные расстояния между точками выборки выравниваются, контраст «свой–чужой» для ближайших соседей падает. Выборочная ковариация в размерности $d$ имеет $O(d^2)$ степеней свободы и при $n\ll d$ плохо обусловлена. Отсюда регуляризация, отбор признаков и снижение размерности.

Стратифицированный K-fold делит выборку на $K$ блоков так, чтобы доля каждого класса в блоке совпадала с долей в полной выборке. Для $k=1,\ldots,K$ модель обучают на всех блоках кроме $k$-го и считают метрику на $k$-м. Итоговая оценка — среднее по $k$. Стратификация не даёт блоку остаться без редкого класса.


## Линейная регрессия: от RSS к нормальным уравнениям


Модель:


```math
\hat{y}_i=w^\top x_i.
```


Свободный член включают в $x_i$ как координату, тождественно равную $1`. Матрица признаков $X\in\mathbb{R}^{n\times d}$ имеет строки $x_i^\top$. Вектор ответов $\mathbf{y}=(y_1,\ldots,y_n)^\top$. Предсказания есть $Xw$.

Квадратичная потеря на выборке даёт сумму квадратов остатков:


```math
\mathrm{RSS}(w)
=\sum_{i=1}^{n}(y_i-w^\top x_i)^2
=\|Xw-\mathbf{y}\|_2^2
=(Xw-\mathbf{y})^\top(Xw-\mathbf{y}).
```


Раскрывают:


```math
\mathrm{RSS}(w)
=w^\top X^\top Xw-2\mathbf{y}^\top Xw+\mathbf{y}^\top\mathbf{y}.
```


Дифференцируют по вектору $w$. Используют $\nabla_w(w^\top Aw)=2Aw$ для симметричной $A$ и $\nabla_w(b^\top w)=b$:


```math
\nabla_w\mathrm{RSS}(w)=2X^\top Xw-2X^\top\mathbf{y}.
```


Стационарная точка удовлетворяет $\nabla_w\mathrm{RSS}(w)=0$, то есть нормальным уравнениям


```math
X^\top X\,w=X^\top\mathbf{y}.
```


Если столбцы $X$ линейно независимы, матрица $X^\top X$ обратима и


```math
\hat{w}=(X^\top X)^{-1}X^\top\mathbf{y}.
```


Геометрически $X\hat{w}$ — ортогональная проекция $\mathbf{y}$ на столбцовое пространство $X$: остаток $\mathbf{y}-X\hat{w}$ ортогонален каждому столбцу $X$, что как раз есть $X^\top(\mathbf{y}-X\hat{w})=0$.

Связь с правдоподобием. Если $y_i=w^\top x_i+\varepsilon_i$ и $\varepsilon_i\sim\mathcal{N}(0,\sigma^2)$ независимы, то


```math
\log L(w)
=-\frac{n}{2}\log(2\pi\sigma^2)
-\frac{1}{2\sigma^2}\mathrm{RSS}(w).
```


Максимизация $\log L(w)$ по $w$ эквивалентна минимизации $\mathrm{RSS}(w)$. Поэтому OLS совпадает с MLE в гауссовской линейной модели.


### Метрики регрессии


```math
\mathrm{MSE}=\frac1n\sum_{i=1}^{n}(y_i-\hat{y}_i)^2,
\qquad
\mathrm{MAE}=\frac1n\sum_{i=1}^{n}|y_i-\hat{y}_i|.
```


MSE совпадает с $\mathrm{RSS}/n$. Крупные остатки входят квадратом, поэтому MSE чувствительнее выбросов, чем MAE.

Потеря Хьюбера с порогом $\delta>0$ для остатка $r=y-\hat{y}$:


```math
\ell_\delta(r)
=
\begin{cases}
\frac12 r^2, & |r|\le\delta,\\[4pt]
\delta\bigl(|r|-\frac12\delta\bigr), & |r|>\delta.
\end{cases}
```


При малых остатках она совпадает с квадратичной потерей и гладка в нуле. При больших ведёт себя линейно по $|r|$, как MAE.

MAPE есть $\frac1n\sum_i|y_i-\hat{y}_i|/|y_i|$ и ломается при $y_i\approx 0$. SMAPE нормирует на $\frac12(|y_i|+|\hat{y}_i|)$ и смягчает асимметрию.


## Логистическая регрессия: от Бернулли к сигмоиде и LogLoss


Метка $y\in\{0,1\}$. Для объекта $x$ модель задаёт вероятность


```math
p(x)=P(Y=1\mid x)\in(0,1),
\qquad
P(Y=0\mid x)=1-p(x).
```


Одно наблюдение:


```math
P(Y=y\mid x)=p(x)^{y}\bigl(1-p(x)\bigr)^{1-y}.
```


При независимых парах $(x_i,y_i)$ правдоподобие


```math
L=\prod_{i=1}^{n}p(x_i)^{y_i}\bigl(1-p(x_i)\bigr)^{1-y_i}.
```


Логарифм:


```math
\ell=\sum_{i=1}^{n}\Bigl(
y_i\log p(x_i)+(1-y_i)\log\bigl(1-p(x_i)\bigr)
\Bigr).
```


Максимизация $\ell$ эквивалентна минимизации


```math
\mathrm{BCE}
=-\frac1n\sum_{i=1}^{n}\Bigl(
y_i\log p(x_i)+(1-y_i)\log\bigl(1-p(x_i)\bigr)
\Bigr).
```


Это бинарная кросс-энтропия, она же LogLoss. Пока сигмоиды нет: нужна лишь модель, выдающая число из $(0,1)$.


### Откуда берётся сигмоида


Линейный предиктор $z=w^\top x+b$ принимает любые вещественные значения. Положить $p(x)=w^\top x+b$ нельзя: правая часть не лежит в $(0,1)$.

Линейно моделируют логарифм шансов:


```math
\log\frac{p(x)}{1-p(x)}=w^\top x+b=:z.
```


Левая часть — логит. Показательная функция обратима:


```math
\frac{p}{1-p}=e^{z}
\implies
p(1+e^{z})=e^{z}
\implies
p=\frac{e^{z}}{1+e^{z}}
=\frac{1}{1+e^{-z}}.
```


Отсюда логистическая сигмоида


```math
\sigma(z)=\frac{1}{1+e^{-z}}
```


и параметризация $p(x)=\sigma(w^\top x+b)$. Сигмоида — обратная к логиту. LogLoss — отрицательное логарифмическое правдоподобие бернуллиевской модели. Вместе они дают логистическую регрессию.


### Вывод градиента BCE


Нужна производная сигмоиды. При $z\in\mathbb{R}$


```math
\sigma'(z)
=\frac{e^{-z}}{(1+e^{-z})^2}
=\frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}
=\sigma(z)\bigl(1-\sigma(z)\bigr).
```


Обозначают $p_i=\sigma(z_i)$, $z_i=w^\top x_i+b$. Вклад $i$-го объекта в BCE:


```math
\ell_i=-y_i\log p_i-(1-y_i)\log(1-p_i).
```


Дифференцируют по $z_i$:


```math
\frac{\partial\ell_i}{\partial z_i}
=-y_i\frac{1}{p_i}p_i'
+(1-y_i)\frac{1}{1-p_i}p_i'.
```


Подставляют $p_i'=\sigma'(z_i)=p_i(1-p_i)$:


```math
\frac{\partial\ell_i}{\partial z_i}
=-y_i(1-p_i)+(1-y_i)p_i
=p_i-y_i.
```


Цепное правило по $w$:


```math
\nabla_w\ell_i
=\frac{\partial\ell_i}{\partial z_i}\cdot x_i
=(p_i-y_i)x_i.
```


Усреднение по выборке:


```math
\nabla_w\mathrm{BCE}
=\frac1n\sum_{i=1}^{n}\bigl(\sigma(w^\top x_i+b)-y_i\bigr)x_i.
```


Гессиан BCE по $w$ равен $\frac1n\sum_i p_i(1-p_i)x_i x_i^\top$ и неотрицательно определён, поэтому функционал выпукл по $w$.


### Многоклассовый случай


Для $K$ классов метка — категория $y\in\{1,\ldots,K\}$. Модель задаёт логиты $z\in\mathbb{R}^K$ и вероятности


```math
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}},
\qquad k=1,\ldots,K.
```


Это Softmax: он отображает $\mathbb{R}^K$ на внутренность симплекса. Правдоподобие одного объекта есть $p_y$. NLL по выборке — категориальная кросс-энтропия


```math
-\frac1n\sum_{i=1}^{n}\log p_{y_i}(x_i).
```


## Регуляризация L2, L1 и Elastic Net


В главе о математике для гауссовской линейной модели и априорного закона $w\sim\mathcal{N}(0,\tau^2 I)$ выведено, что MAP совпадает с


```math
\hat{w}
=\arg\min_w\Bigl(\mathrm{RSS}(w)+\lambda\|w\|_2^2\Bigr),
\qquad
\lambda=\frac{\sigma^2}{\tau^2}.
```


Дифференцирование этого критерия даёт


```math
\nabla_w\bigl(\mathrm{RSS}(w)+\lambda\|w\|_2^2\bigr)
=2X^\top Xw-2X^\top\mathbf{y}+2\lambda w.
```


Приравнивание к нулю:


```math
(X^\top X+\lambda I)\hat{w}=X^\top\mathbf{y}.
```


Слагаемое $\lambda I$ сдвигает спектр $X^\top X$ на $\lambda$ и делает матрицу обратимой даже при линейно зависимых столбцах.

Для лапласовского априорного закона MAP есть


```math
\hat{w}=\arg\min_w\Bigl(\mathrm{RSS}(w)+\lambda\|w\|_1\Bigr).
```


Те же штрафы пишут рядом с BCE. Для бернуллиевского правдоподобия и гауссовского априорного закона на $w$ задача $\min(\mathrm{BCE}+\lambda\|w\|_2^2)$ снова есть MAP.

Штраф $\|w\|_2^2$ сжимает координаты непрерывно. Штраф $\|w\|_1$ из-за углов единичного шара нормы $\ell_1$ часто обнуляет часть координат.

Elastic Net:


```math
\min_w\ \mathrm{RSS}(w)
+\lambda\bigl(\alpha\|w\|_1+(1-\alpha)\|w\|_2^2\bigr).
```


Член $\ell_2$ стабилизирует оценку при коррелированных признаках. Член $\ell_1$ сохраняет разреженность. Параметры $\lambda$ и $\alpha$ выбирают по валидации.


## Метрики классификации


По порогу $t$ на вещественном score $s(x)$ предсказывают класс $1$, если $s(x)\ge t$. Сравнивая с истинными метками, получают числа TP, FP, FN, TN.


```math
\mathrm{Recall}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}},
\qquad
\mathrm{Precision}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}},
\qquad
\mathrm{FPR}=\frac{\mathrm{FP}}{\mathrm{FP}+\mathrm{TN}}.
```


Recall — доля найденных положительных среди всех положительных. Precision — доля истинных положительных среди предсказанных положительными. F1 — гармоническое среднее Precision и Recall:


```math
F_1=\frac{2\cdot\mathrm{Precision}\cdot\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}.
```


Гармоническое среднее сильно падает, если один из множителей мал. Поэтому F1 требует одновременно ненулевых Precision и Recall.

Macro-F1 усредняет F1 по классам с равными весами. Micro-F1 сначала суммирует TP, FP, FN по классам, затем считает одну F1. Weighted-F1 взвешивает классы по числу объектов.

ROC-кривая — параметрический путь $(\mathrm{FPR}(t),\mathrm{Recall}(t))$ при изменении порога $t$. ROC-AUC равна вероятности


```math
P\bigl(s(x_+)>s(x_-)\bigr),
```


где $x_+$ — случайный объект положительного класса, $x_-$ — случайный объект отрицательного класса, независимые. Это следует из представления площади под ROC через интеграл по порогам и переходе к сравнению двух независимых score.

PR-кривая строится в осях Recall и Precision. При сильном дисбалансе отрицательный класс раздувает TN и делает ROC оптимистичной. PR смотрит только на положительный класс и Precision.

Каппа Коэна. Пусть $p_o$ — доля объектов, где предсказание совпало с меткой. Пусть $p_e$ — вероятность совпадения, если предсказание и метка независимы и имеют те же маргинальные частоты классов. Тогда


```math
\kappa=\frac{p_o-p_e}{1-p_e}.
```


Числитель — улучшение над случайным согласием. Знаменатель нормирует на максимально возможное улучшение.


## SVM: зазор, мягкий зазор, ядра


Метки кодируют $y_i\in\{-1,+1\}$. Ищут гиперплоскость $w^\top x+b=0$. Для точки $x$ расстояние до плоскости равно


```math
\frac{|w^\top x+b|}{\|w\|_2}.
```


Пусть ограничения нормированы так, что на опорных объектах $y_i(w^\top x_i+b)=1$. Тогда две опорные плоскости есть $w^\top x+b=\pm 1$. Подставляют точку одной опорной плоскости в формулу расстояния до другой: разность значений линейной функции равна $2$, значит геометрический зазор равен


```math
\frac{2}{\|w\|_2}.
```


Максимизация зазора эквивалентна минимизации $\|w\|_2$ при правильной классификации с запасом. Задача жёсткого зазора:


```math
\min_{w,b}\ \frac12\|w\|_2^2
\quad\text{при}\quad
y_i(w^\top x_i+b)\ge 1
\quad\text{для всех }i.
```


Множитель $\frac12$ удобен при дифференцировании и не меняет argmin.

Если выборка неразделима, вводят $\xi_i\ge 0$ — величину нарушения для объекта $i$. Требуют


```math
y_i(w^\top x_i+b)\ge 1-\xi_i,
\qquad
\xi_i\ge 0.
```


Штрафуют сумму нарушений:


```math
\min_{w,b,\xi}\ \frac12\|w\|_2^2+C\sum_{i=1}^{n}\xi_i.
```


Параметр $C>0$ задаёт цену нарушения относительно ширины зазора.

Эквивалентность hinge-потере. При фиксированных $w,b$ оптимальный $\xi_i$ есть ровно величина недотягивания до запаса $1$:


```math
\xi_i^{\star}=\max\bigl(0,\,1-y_i(w^\top x_i+b)\bigr).
```


Подстановка в целевую функцию даёт


```math
\min_{w,b}\ \frac12\|w\|_2^2
+C\sum_{i=1}^{n}\max\bigl(0,\,1-y_i(w^\top x_i+b)\bigr).
```


Двойственная задача. Лагранжиан жёсткого или мягкого зазора после исключений зависит от данных через скалярные произведения $\langle x_i,x_j\rangle$. Решение имеет вид $w=\sum_i\alpha_i y_i x_i$. Предсказание


```math
w^\top x+b=\sum_i\alpha_i y_i\langle x_i,x\rangle+b.
```


Ядерный трюк заменяет $\langle x,x'\rangle$ на $K(x,x')=\langle\phi(x),\phi(x')\rangle$ для некоторого признакового отображения $\phi$, которое явно строить не нужно. Достаточно уметь считать $K$.

Линейное ядро: $K(x,x')=x^\top x'$.  
Полиномиальное: $K(x,x')=(x^\top x'+c)^d$.  
RBF:


```math
K(x,x')=\exp\bigl(-\gamma\|x-x'\|^2\bigr).
```


Параметр $\gamma$ задаёт ширину локальности. Перед ядерным SVM признаки масштабируют, иначе евклидовы нормы координат несравнимы.


## Случайный лес и OOB


Решающее дерево рекурсивно делит пространство признаков. Глубокое дерево гибко приближает $f^{\star}$, но сильно зависит от выборки: смещение мало, дисперсия велика.

Пусть есть $B$ почти несмещённых оценок $\hat{f}^{(1)},\ldots,\hat{f}^{(B)}$ с дисперсией $\sigma^2$ и средней попарной корреляцией $\rho$. Для среднего


```math
\bar{f}=\frac1B\sum_{b=1}^{B}\hat{f}^{(b)}
```


верно


```math
\mathrm{Var}(\bar{f})
=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2.
```


При $\rho=0$ дисперсия падает как $1/B$. При $\rho$ близком к $1$ усреднение почти не помогает. Бэггинг и случайные подпространства признаков как раз уменьшают $\rho$.

Случайный лес для каждого $b=1,\ldots,B$:
1. берёт бутстрэп-выборку объектов;
2. при каждом разбиении дерева рассматривает случайные $m$ признаков из $d$;
3. растят дерево до критерия остановки.

Итог — голосование или усреднение по деревьям.

OOB. Объект $i$ не попал примерно в треть бутстрэпов. Предсказание по деревьям, где $i$ был вне бутстрэпа, даёт оценку ошибки без отдельной валидационной выборки.


## Градиентный бустинг


Ищут аддитивную модель


```math
F_M(x)=\sum_{m=1}^{M}\nu\,h_m(x),
```


где $h_m$ лежит в классе деревьев, $\nu\in(0,1]$ — длина шага. На шаге $m$ уже построена $F_{m-1}$. Хотят выбрать $h_m$, минимизируя


```math
\sum_{i=1}^{n}\ell\bigl(y_i,\,F_{m-1}(x_i)+h(x_i)\bigr).
```


При малом шаге раскладывают потерю по добавке $h(x_i)$ до первого порядка:


```math
\ell\bigl(y_i,F_{m-1}(x_i)+h(x_i)\bigr)
\approx
\ell\bigl(y_i,F_{m-1}(x_i)\bigr)
+\frac{\partial\ell(y_i,F)}{\partial F}\Big|_{F=F_{m-1}(x_i)}\,h(x_i).
```


Сумма по $i$ с точностью до константы равна $-\sum_i r_{im}h(x_i)$, где


```math
r_{im}
=-\frac{\partial\ell(y_i,F(x_i))}{\partial F(x_i)}\Big|_{F=F_{m-1}}.
```


Минимизация линейного приближения по $h$ из класса деревьев сводится к тому, чтобы $h$ приближало поле псевдоостатков $\{r_{im}\}$. На практике дерево $h_m$ учат регрессии на $\{(x_i,r_{im})\}$. Затем обновляют


```math
F_m=F_{m-1}+\nu h_m.
```


Так получают метод градиентного бустинга.


### XGBoost: откуда вес листа


Раскладывают потерю по добавке дерева $h$ до второго порядка. Обозначают


```math
g_i=\frac{\partial\ell(y_i,F)}{\partial F}\Big|_{F=F_{m-1}(x_i)},
\qquad
h_i=\frac{\partial^2\ell(y_i,F)}{\partial F^2}\Big|_{F=F_{m-1}(x_i)}.
```


Здесь $h_i$ — гессиан по предсказанию, не дерево. Приближённый прирост потери:


```math
\sum_{i=1}^{n}\Bigl(
g_i h(x_i)+\frac12 h_i h(x_i)^2
\Bigr)
+\Omega(h),
```


где $\Omega$ — регуляризатор на дерево. Пусть дерево задаёт разбиение объектов на листья $\{I_j\}$ и константный вес $w_j$ в листе $j$, то есть $h(x_i)=w_{j(i)}$. Регуляризатор берут


```math
\Omega=\gamma|J|+\frac\lambda2\sum_{j=1}^{J}w_j^2,
```


где $|J|$ — число листьев. Тогда целевая функция распадается по листьям:


```math
\sum_{j=1}^{J}\Biggl(
\Bigl(\sum_{i\in I_j}g_i\Bigr)w_j
+\frac12\Bigl(\sum_{i\in I_j}h_i+\lambda\Bigr)w_j^2
\Biggr)
+\gamma|J|.
```


Для фиксированного разбиения минимизируют квадратичную функцию по $w_j$. Производная по $w_j$:


```math
\sum_{i\in I_j}g_i+\Bigl(\sum_{i\in I_j}h_i+\lambda\Bigr)w_j=0.
```


Отсюда оптимальный вес листа


```math
w_j^{\star}
=-\frac{\sum_{i\in I_j}g_i}{\sum_{i\in I_j}h_i+\lambda}.
```


Параметр $\lambda$ увеличивает знаменатель и сжимает веса листьев.


### LightGBM и CatBoost


LightGBM растят дерево, выбирая на каждом шаге лист с наибольшим уменьшением потери, дискретизирует признаки гистограммами, усиливает объекты с большими $|g_i|$ и объединяет взаимоисключающие разреженные признаки.

CatBoost кодирует категориальные признаки упорядоченными статистиками целевой переменной, чтобы метка объекта не утекала в его же признак при кодировании, и использует симметричные деревья.

Лес снижает дисперсию усреднением. Бустинг жадно снижает эмпирический риск и чувствителен к числу деревьев $M$ и к шагу $\nu$. Early stopping выбирает $M$ по валидационной метрике.
